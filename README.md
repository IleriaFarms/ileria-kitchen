# Ileria Kitchen

Internal recipe costing, pricing, and production-planning prototype for Ileria Farms.

## V1 goals
- Ingredient library with package pricing and supplier tracking
- Recipe builder with unit-aware ingredient costing
- Prep/cook labor costing
- Batch cost, unit cost, target-margin and markup pricing
- Local browser persistence and JSON backup/restore
- Seed recipes for calculation validation

## Development
Active work is developed on feature branches and reviewed through pull requests before merging into `main`.

> Note: this repository is currently public. Do not commit credentials, API keys, customer data, or other secrets.
